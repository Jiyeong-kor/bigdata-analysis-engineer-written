# 빅데이터분석기사 필기 학습 앱

아이폰 13 mini를 포함한 모바일 환경에서 빅데이터분석기사 필기 기출문제를 한 문항씩 풀고, 필요한 순간 개념 학습으로 전환할 수 있는 개인 학습용 PWA입니다.

## 재사용한 검증 자산

- Notion의 최신 `빅데이터분석기사 기출문제 12회 (2026.04.04)` 80문항과 정답·핵심 해설
- Notion에 보강된 33번 선택지와 21번·63번 학습용 상자그림
- 기존 ADsP·빅데이터 학습 자료에서 효과가 확인된 한 문항씩 풀기 방식
- `모르겠음`, 첫 답안, 정오, 자신감, 해설 확인, 오답 이유, 풀이 시간 저장 구조
- 브라우저 저장소 기반 중단·이어풀기, JSON 백업·복원, 오프라인 실행

## 주요 기능

- 전체 80문항, 과목별 20문항, 미풀이 문항, 오답·모르겠음 재시험
- 해설 확인 전 다음 문항 이동 방지
- 최근 5문항 중 3문항 이상 오답·모르겠음 또는 같은 개념 2회 이상 취약 시 개념 복습 권고
- 정의 → 판단 기준 → 혼동 개념 → 예시 → 미니 확인 순서의 개념 학습
- iPhone Safe Area와 작은 화면 대응

## 배포

GitHub Pages를 사용합니다. 저장소의 `Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 선택하면 별도 서비스 계정 없이 무료로 배포됩니다.
