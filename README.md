# 빅데이터분석기사 필기 학습 앱

아이폰 13 mini를 포함한 모바일 환경에서 빅데이터분석기사 필기 문제를 한 문항씩 풀고, 필요한 순간 개념 학습으로 전환할 수 있는 개인 학습용 PWA입니다.

## 학습 자료

Notion에 정리한 자료와 실제 앱 풀이 기록을 재사용하여 총 224문항으로 구성했습니다.

- 제12회 기출복원 80문항
- 자가진단 40문항
- 네 과목 핵심 교재와 세부 출제범위 보강을 시험형으로 바꾼 교재 변형 95문항
- 2026-09-04 학습 기록에서 NoSQL 제품과 Chukwa 판단 기준을 보강한 5문항
- 2026-09-04 21:31 적응형 재시험에서 반복 `모르겠음`으로 확인된 비모수 검정 선택 기준을 다른 상황으로 바꾼 4문항
- 33번의 보강 선택지와 21번·63번 학습용 상자그림

## 오늘의 8문제

앱의 실제 풀이 기록과 Notion에 누적한 이해 상태를 비교하여 더 최근에 갱신된 쪽만 현재 학습 상태로 사용합니다.

- 네 과목에서 2문항씩 출제하여 매일 과목별 진단을 유지합니다.
- 앱 답안의 `answeredAt`과 Notion 학습 프로필의 `updatedAt`을 비교합니다.
- Notion 갱신 뒤에 앱에서 다시 풀었다면 앱 결과가 최신 상태가 됩니다.
- 앱에서 푼 뒤 Notion에서 다시 공부하여 상태를 갱신했다면 Notion 상태가 최신 상태가 됩니다.
- 더 오래된 쪽의 오답·정답·취약 가중치는 현재 출제 판단에서 제외합니다.
- 앱이 최신인 개념에서는 최신 앱 결과만 사용하여 오답·모르겠음·정답을 판정합니다.
- Notion이 최신인 개념에서는 `미암기`, `보강 중`, `이해 완료` 등 Notion 상태를 출제 가중치에 사용합니다.
- 아직 풀지 않은 문제를 우선하되, 과거에 이미 푼 문항을 Notion 갱신 때문에 새 문항으로 잘못 세지 않습니다.
- 같은 문항을 반복해서 외우는 효과보다 같은 개념을 새로운 상황에 적용하는 능력을 확인할 수 있도록 취약 개념의 변형문제를 우선할 수 있습니다.
- ADsP와 겹치는 범위만 반복하지 않고 플랫폼·수집·저장·거버넌스·모형 운영처럼 빅데이터분석기사에서 추가되는 영역에도 가중치를 둡니다.
- 같은 한국 날짜에는 같은 8문제를 유지합니다. 선정 기준 버전이 바뀌면 그날의 세트도 새 기준으로 다시 생성합니다.
- 정답은 제출하기 전에 공개하지 않으며, 제출한 직후 해설을 표시합니다.

## 주요 기능

- 오늘의 8문제: 앱과 Notion 중 최신 학습 상태를 기준으로 구성하는 적응형 세트
- 통합 실전 40문항: 네 과목에서 10문항씩 뽑고 미풀이 문항을 우선 구성
- 문제은행별 풀이: 기출복원, 자가진단, 교재·Notion 변형
- 과목별 전체 문제, 미풀이 문제, 오답·헷갈림 재시험
- 정답 확인과 동시에 해설 및 다음 문제 버튼 표시
- 최근 5문항 중 3문항 이상이 오답·불확실하거나 같은 개념에서 2회 이상 막히면 개념 복습 권고
- 정의 → 판단 기준 → 혼동 개념 → 예시 → 미니 확인 순서의 개념 학습
- 답안, 자신감, 오답 이유, 풀이 시간, 중단 위치 자동 저장
- JSON 백업·복원과 서비스 워커 기반 오프라인 실행
- iPhone Safe Area와 작은 화면 대응

## UI 원칙

- 학습과 직접 관련 없는 대형 문구와 장식용 히어로 영역을 사용하지 않습니다.
- 첫 화면에는 현재 진도와 시작할 문제 묶음을 우선 배치합니다.
- 정답을 확인한 뒤 별도의 ‘해설 확인 완료’ 절차를 요구하지 않습니다.
- 메모 입력창은 기본적으로 접어 두어 문제 풀이 흐름을 방해하지 않습니다.
- 큰 카드보다 정보 밀도와 터치 편의성을 우선합니다.

## 배포

GitHub Pages를 사용합니다. 저장소의 `Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 선택하면 별도 서비스 계정 없이 무료로 배포됩니다.
