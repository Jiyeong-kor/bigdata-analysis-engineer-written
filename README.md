# 빅데이터분석기사 필기 학습 앱

아이폰 13 mini를 포함한 모바일 환경에서 빅데이터분석기사 필기 문제를 한 문항씩 풀고, 필요한 순간 개념 학습으로 전환할 수 있는 개인 학습용 PWA입니다.

## 학습 자료

Notion에 정리한 자료를 새로 만들지 않고 재사용하여 총 215문항으로 구성했습니다.

- 제12회 기출복원 80문항
- 자가진단 40문항
- 네 과목 핵심 교재와 세부 출제범위 보강을 시험형으로 바꾼 교재 변형 95문항
- 33번의 보강 선택지와 21번·63번 학습용 상자그림

## 오늘의 8문제

과거 ChatGPT 채팅 `빅데이터분석기사 매일학습`에서 사용한 출제 기준을 앱의 적응형 세트에 반영했습니다.

- 네 과목에서 2문항씩 출제하여 매일 과목별 진단을 유지합니다.
- 직전 오답, `모르겠음`, 확신 없이 맞힌 문항과 같은 취약 영역을 우선합니다.
- 취약 강도는 `모르겠음 → 오답 → 확신 없는 정답` 순으로 다르게 반영합니다.
- 같은 개념에서 취약 응답이 반복되면 그 개념의 다른 문항도 우선순위를 높입니다.
- 자신 있게 맞힌 개념은 반복 우선순위를 낮춥니다.
- 아직 풀지 않은 문제를 우선합니다.
- ADsP와 겹치는 범위만 반복하지 않고, 플랫폼·수집·저장·거버넌스·모형 운영처럼 빅데이터분석기사에서 추가되는 영역에 가중치를 둡니다.
- 같은 한국 날짜에는 같은 8문제를 유지하고, 다음 날에는 전날의 답안 기록을 반영하여 새 세트를 만듭니다.
- 정답은 제출하기 전에 공개하지 않으며, 제출한 직후 해설을 표시합니다.

## 주요 기능

- 오늘의 8문제: 오답·취약 영역과 빅데이터분석기사 추가영역을 반영한 적응형 세트
- 통합 실전 40문항: 네 과목에서 10문항씩 뽑고 미풀이 문항을 우선 구성
- 문제은행별 풀이: 기출복원, 자가진단, 교재 변형
- 과목별 전체 문제, 미풀이 문제, 오답·헷갈림 재시험
- 정답 확인과 동시에 해설 및 다음 문제 버튼 표시
- 최근 5문항 중 3문항 이상이 오답·불확실하거나 같은 개념에서 2회 이상 막히면 개념 복습 권고
- 정의 → 판단 기준 → 혼동 개념 → 예시 → 미니 확인 순서의 개념 학습
- 답안, 자신감, 오답 이유, 풀이 시간, 중단 위치 자동 저장
- JSON 백업·복원과 서비스 워커 기반 오프라인 실행
- iPhone Safe Area와 작은 화면 대응

## UI 원칙

- 학습과 직접 관련 없는 대형 문구와 장식용 히어로 영역을 사용하지 않습니다.
- 첫 화면에는 현재 진도와 시작할 문제 묶음을 우선 배치합니다.
- 정답을 확인한 뒤 별도의 ‘해설 확인 완료’ 절차를 요구하지 않습니다.
- 메모 입력창은 기본적으로 접어 두어 문제 풀이 흐름을 방해하지 않습니다.
- 큰 카드보다 정보 밀도와 터치 편의성을 우선합니다.

## 배포

GitHub Pages를 사용합니다. 저장소의 `Settings → Pages → Build and deployment → Source`에서 `GitHub Actions`를 선택하면 별도 서비스 계정 없이 무료로 배포됩니다.
